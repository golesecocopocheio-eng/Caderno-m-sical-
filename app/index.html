🍸 Entrar no bar

Use o mesmo código do bar em todos os celulares da equipe para os dados sincronizarem. Quem cria o código primeiro vira o dono.

Escolha um código difícil de adivinhar: quem souber o código consegue ver e mudar os dados.

💾 Backup

Guarde uma cópia de tudo (Caixa, Portaria e Estoque) ou traga de volta uma cópia salva.

♻️ Restaurar

Aceita o backup completo, o do Caixa, da Portaria ou do Estoque, o arquivo dados-do-bar.json ou o resumo da noite da Portaria. Cada parte volta para a aba certa.
